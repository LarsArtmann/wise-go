# Go 1.27 Migration Plan

**Date:** 2026-10-07
**Status:** DESIGNED — execution is condition-triggered, not date-triggered. Do not start until all four unlock conditions hold.
**Source:** `docs/status/2026-10-07_03-45_buildflow-red-to-green-repair-status.md` §g1, the 2026-10-07 modernizer-sweep incident (AGENTS.md, kin-openapi Dependencies entry), and the erraudit install constraint (AGENTS.md, Dependencies).

---

## Executive Summary

wise-go pins go 1.26 (directive `go 1.26`, nixpkgs toolchain 1.26.8, `GOTOOLCHAIN=local`) while the surrounding ecosystem has moved to 1.27: `erraudit` requires ≥ 1.27 and cannot install locally, and the buildflow modernizer keeps pushing 1.27-only syntax into the tree — which we revert per incident because the toolchain cannot compile it. The cost of staying pinned is a recurring repair tax (four go-directive fights as of 2026-10-07, the worst deleting `.buildflow.yml` and rewriting `errors_test.go` in one window) plus a permanently CI-only erraudit gate. The cost of flipping early is broken builds.

This plan defines the flip as **four unlock conditions + a single-commit procedure with a single-commit rollback**. No date is committed; the conditions are cheap to re-check.

## Why 1.26 is pinned today

1. **nixpkgs-26.11 default `pkgs.go` is 1.26.x** — the repo pins the directive to the nixpkgs toolchain line; the invariant that matters is directive ≤ the flake's Go.
2. **GOEXPERIMENT=jsonv2 is mandatory** — `go-branded-id v0.5.1` and `go-error-family v0.10.0` import `encoding/json/v2`. Every Go invocation (dev shell, buildflow `env:`, golangci build tags, the flake's `md-go-snippets` check) must carry it. This constraint is INDEPENDENT of the 1.26/1.27 choice and does not change in this migration.
3. **buildflow fights the pin** — `go-version-auto-configure` and `go-structure-linter` (rule `go-version`) auto-bump the directive while `go-mod-normalize` deliberately rewrites patch-pins to minor form. Mitigated via `skip_steps`; removing those skips is itself part of the flip.

## The four unlock conditions

All four must hold. Check them in order; stop at the first failure.

| # | Condition | How to verify |
| - | --------- | ------------- |
| 1 | nixpkgs default `pkgs.go` is stable 1.27.x (not an RC, not 1.28-only) | `nix eval nixpkgs#go.version` → `1.27.x` |
| 2 | In-house deps verified on 1.27: `go-branded-id`, `go-error-family`, `go-retry` build, race-test, and apidiff clean under a 1.27 toolchain | In each repo's dev shell on 1.27: `go test -race ./...` + `nix run .#apidiff` (or gorelease equivalent) |
| 3 | `erraudit` installs locally (`go install github.com/larsartmann/erraudit@<pin>` with `ERRAUDIT_TOKEN` + `GOPRIVATE`) and `erraudit lint ./... --type-aware --enforce-coded-errors` is exit-0 on this tree | Run it; expect the same clean verdict as the CI job |
| 4 | buildflow's `go-version-auto-configure` and `go-structure-linter` `skip_steps` can be removed without the run touching `go.mod` | Temporarily re-enable both, run buildflow once on a scratch branch, confirm `git diff` is empty, re-skip until flip day |

Condition 2 can be pre-verified opportunistically; conditions 1 and 4 are the actual gate.

## Flip procedure (single commit)

One commit, one revert. The commit contains every toolchain surface in the repo; nothing half-flipped survives a night.

1. **flake.nix** — switch the package/toolchain references from the 1.26 line to default `pkgs.go` (1.27.x). The `md-go-snippets` check's `(pkgs.buildGoModule.override { go = pkgs.go_1_27; })` collapses to plain `buildGoModule`; recompute `vendorHash` if the go version change alters it (it did for 1.26→1.27; use the fake-hash dance to surface the real value). Re-pin the flake.lock nixpkgs input only if the locked rev predates the 1.27 default.
2. **go.mod** — bump the directive to `go 1.27` (minor form; `go-mod-normalize` will keep it there). `go.sum`/vendor untouched unless a dep bumps.
3. **.buildflow.yml** — remove the `go-version-auto-configure` and `go-structure-linter` `skip_steps` (condition 4). KEEP the `erraudit` skip until the embedded-analyzer defect is fixed upstream (class-wide policy, AGENTS.md). KEEP `env: GOEXPERIMENT: jsonv2`.
4. **.golangci.yml** — no change expected (build tags unchanged); verify with `golangci-lint run`.
5. **Adopt 1.27 syntax ONLY after this commit lands** — e.g. the promoted-field struct literals the modernizer pushed into `errors_test.go` on 2026-10-07 are welcome AFTER the flip, never before. Signature of premature adoption: `UnsupportedFeature ... requires go1.27 or later`.
6. **Verify** (full chain, in order): `nix run .#pre-release` (dirty-tree guard → build → vet → race → golangci-lint → `nix flake check` → doc-verify → release-notes-check → apidiff), then `go test -shuffle=on .` × 6–10, then a fuzz smoke (`-fuzz FuzzDecodeExchangeRates -fuzztime 8s`).
7. **Update memory** — AGENTS.md gotchas that encode the pin (go directive invariant, GOEXPERIMENT injection sites, modernizer non-fix rulings) get rewritten the same day; stale "we are on 1.26" memory is how the next session re-fights the old war.

## Rollback (single commit)

`git revert <flip-commit>`. Known recovery path from the 2026-10-07 incident if the tree is dirty instead: `git show <pre-sweep-commit>:<file>` to restore `go.mod`, rewritten files, and `.buildflow.yml` from history. If nixpkgs moved on and 1.26 is gone from the default input, pin the previous nixpkgs rev in flake.lock as part of the revert.

## Residual risks

- **buildflow recurrence** — if any buildflow step touches `go.mod` after the flip, re-skip that step and file it as a fifth defect rather than hand-patching the directive in place.
- **md-go-validator coupling** — once the default go is 1.27, upstream's flake may build its own package again; switching the flake input from source-only back to upstream's flake is an OPTIONAL cleanup, not part of the flip.
- **LSP divergence** — the golangci LSP wrapper lacks `GOEXPERIMENT=jsonv2` (prime phantom suspect, TODO_LIST P3); fixing the wrapper is INDEPENDENT of this migration but should land before it so flip-day diagnostics are trustworthy.
- **GOEXPERIMENT=jsonv2 retirement** — tracked separately: when go-branded-id and go-error-family drop their json/v2 imports, remove the env from flake devShells, `.buildflow.yml`, and `.golangci.yml` in one commit.

## Re-check cadence

Grep for the trigger on any session that touches toolchain/deps: `nix eval nixpkgs#go.version`. When it prints 1.27.x, start at condition 2 and execute the same day — a flip whose preconditions are green is cheaper than one more modernizer-incident repair.
