## e) WHAT WE SHOULD IMPROVE

1. **Gate-order discipline as a checklist, not memory.** The anchor-check-after-.go-edits rule failed because it lived in AGENTS prose and my working memory, not in the execution loop. Improvement: after any commit touching `*.go`, run `nix run .#anchor-check` as part of the SAME command chain as the commit — or wire anchor-check into the pre-commit hook so the daemon's sweeps cannot bury a drift.
2. **Read the pinned dependency's interface BEFORE building mechanisms.** M24 cost 3 attempts because the go-standard module's `systems` mkOption was discoverable in `modules/go-standard.nix` from minute one. Rule for next time: for any flake-module knob, `grep systems/modules` of the PINNED source first.
3. **Environment hygiene before long jobs.** Check `df /tmp` + competing nix/go processes before: bench captures, background flake checks, releases. One `ps aux | grep nix` + `df -h /tmp` at session start and before each long job would have saved the polluted capture, both signing failures, and the apidiff retry.
4. **Lint-then-commit, always** — even for doc-only changes; the amend pattern works but is a smell.
5. **Baseline captures get a load check in the script itself.** The bench README now documents the hygiene rule; the next step is mechanical: the capture loop could refuse to start when 1-minute load exceeds a threshold (or record load alongside the samples so benchstat output carries the caveat).
6. **Autonomous repo-side changes get a flag list in the final report.** D5, Discussions, and M22's resolution were all reversible and documented in-commit, but they should have been gathered into one "ratify-or-revert" list up front (this report's §g-3 does that now).
7. **Deduplicate-before-compress on living docs.** The AGENTS compression pass's best win wasn't shorter sentences — it was finding the erraudit skip_steps split-brain (two bullets disagreeing about a resolved state). A periodic "do the living docs contradict themselves" sweep would catch the class; the anchor-check catches line rot, not claim rot.
8. **The parity gate deserves a home in automation.** `spec_drift_parity.py` is manual-only; if the regex extractor rots (or the go extractor changes), the parity breaks silently between runs. Candidate: fold it into `checks.script-fixtures` (cheap: two extractor runs + set compare).
